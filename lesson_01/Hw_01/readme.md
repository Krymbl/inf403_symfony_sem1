Домашнее задание к вводной лекции
Задание 1. Консольный калькулятор
Скрипт запрашивает у пользователя ввод через консоль (readline или STDIN): два числа и оператор (+, -, *, /). Выводит результат. При делении на 0 и некорректном операторе — сообщение об ошибке.

Пример ввода:

Введите первое число: 10
Введите второе число: 0
Введите оператор (+, -, *, /): /
Пример вывода:

Ошибка: деление на ноль
