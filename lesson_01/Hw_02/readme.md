Задание 2. Обработка данных из файла
В файле students.txt построчно записаны студенты в формате Имя;Оценка1,Оценка2,Оценка3. Скрипт считывает файл, для каждого студента считает средний балл, выводит список, отсортированный по среднему баллу по убыванию, и выводит имя студента с максимальным средним баллом.

Пример содержимого students.txt:

Анна;4,5,5
Иван;3,3,4
Пётр;5,5,5
Пример вывода:

Пётр: 5.00
Анна: 4.67
Иван: 3.33
Лучший студент: Пётр
