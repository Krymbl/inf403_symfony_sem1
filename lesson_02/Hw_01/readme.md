# Домашнее задание 2
## Работа с 2 разными API через GUZZLE

Написать скрипт weather_guzzle.php, который

* Отправляет GET-запрос при помощи Guzzle к публичному погодному API (например, wttr.in)
* Получает данные (прогноз погоды).
* Декодирует JSON-ответ.
* Обработка ошибок:
* Если ответ не 200 — вывести сообщение об ошибке.
* Если JSON некорректен — отработать исключение.
* Формирует из полученных данных новый JSON, содержащий статус ответа и первые 3 результата первого запроса
* Отправляет POST-запрос на JSONPlaceholder или другой ресурс для эмуляции API со сформированным JSON, обрабатывает ошибки и выводит окончательный результат
